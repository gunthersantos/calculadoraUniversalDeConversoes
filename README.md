# 🔄 Calculadora Universal de Conversões

Aplicação web moderna para conversão de unidades de medida, peso, temperatura, velocidade e muito mais. Desenvolvida com React, Tailwind CSS e Framer Motion.

![GitHub repo size](https://img.shields.io/github/repo-size/gunthersantos/calculadoraUniversalDeConversoes)
![GitHub last commit](https://img.shields.io/github/last-commit/gunthersantos/calculadoraUniversalDeConversoes)
![License](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ Funcionalidades

- 📏 **8 Categorias** de conversão: Comprimento, Massa, Temperatura, Velocidade, Volume, Área, Tempo e Dados Digitais
- 🔄 **Inversão rápida** de unidades com animação suave
- 💾 **Histórico persistente** salvo no localStorage (até 50 conversões)
- 📋 **Copiar resultado** com um clique
- 📱 **Design responsivo** mobile-first com glassmorphism
- 🎨 **Animações fluidas** com Framer Motion
- ⚡ **Conversão em tempo real** enquanto digita

## 📋 Categorias de Conversão

| Categoria | Unidades Disponíveis |
|-----------|---------------------|
| **Comprimento** | mm, cm, m, km, pol, ft, yd, mi |
| **Massa** | mg, g, kg, ton, lb, oz |
| **Temperatura** | °C, °F, K |
| **Velocidade** | m/s, km/h, mph, nós |
| **Volume** | ml, l, m³, gal, fl oz |
| **Área** | cm², m², ha, km², acre |
| **Tempo** | ms, s, min, h, dia, sem, mês, ano |
| **Dados Digitais** | bit, B, KB, MB, GB, TB |

---

## 🎯 Fatores de Conversão

Todas as conversões seguem o **Sistema Internacional de Unidades (SI)**:
- 1 grama = 0,001 quilograma
- 1 metro = 1.000 milímetros
- Temperatura usa fórmulas exatas (°C × 9/5 + 32 = °F)
